Destination et versions

Choisissez où placer votre sauvegarde et gérez les versions conservées.

Dossier de sauvegarde

Aucune destination choisie.

Versions

Chaque sauvegarde crée un dossier daté complet. Sur un disque NTFS, les fichiers inchangés ne sont pas recopiés : ils sont partagés avec la version précédente, seules les nouveautés prennent de la place. Au-delà du nombre choisi, les versions les plus anciennes sont supprimées.

Paramètres

Sauvegarde automatique, contrôle des copies et mises à jour de l’application.

Sauvegarde automatique

Une tâche Windows vérifie toutes les 30 minutes si une sauvegarde est due et si le disque de destination est branché : la sauvegarde démarre peu après le branchement du disque, sans ouvrir l’application. Les exports Wi-Fi et pilotes sont ignorés sans droits administrateur.

Protection des données sensibles

Vos clés de licence et mots de passe Wi-Fi ne sont jamais copiés en clair sur le disque de sauvegarde : ils y sont chiffrés. Le mot de passe n’est demandé que pour les restaurer, sur ce PC ou sur un nouveau ; les sauvegardes, même automatiques, n’en ont pas besoin.

Contrôle des copies

Recommandé : détecte un support défectueux. La sauvegarde dure un peu plus longtemps. Chaque version peut aussi être revérifiée plus tard depuis Outils → Vérifier une sauvegarde.

Fichiers personnels

Dossiers standards

Le dossier « Saved Games » est également inclus lorsqu’il existe.

Dossiers personnalisés

Exclusions

Noms de dossiers ou de fichiers ignorés dans vos fichiers personnels et dossiers personnalisés. Les motifs sont acceptés : « *.iso » exclut toutes les images disque.

Fichiers OneDrive disponibles uniquement en ligne

Si vos dossiers sont synchronisés avec OneDrive, certains fichiers peuvent n’exister que dans le cloud.

Navigateurs

Chrome, Edge, Firefox, Brave, Vivaldi, Opera et Opera GX. Fermez les navigateurs avant la copie.

Les mots de passe Chromium restent chiffrés par Windows et peuvent ne pas fonctionner après réinstallation.

Licences

Conservez vos clés logicielles dans le dossier de sauvegarde.

Clé Windows OEM

Aucune recherche effectuée.

Ajouter une licence

La liste reste sur ce PC, protégée par votre session Windows. Chaque sauvegarde en emporte une copie chiffrée avec votre mot de passe de protection.

Logiciels

La liste des programmes installés est exportée pour pouvoir les réinstaller avec Winget sur un nouveau PC.

Inventaire des programmes

Un export Winget au format JSON et une liste texte seront placés dans la destination choisie.

Un logiciel précis, avec ses paramètres

Pour copier les réglages d’un logiciel et préparer sa réinstallation (installeur MSI / EXE), utilisez l’outil dédié.

Sauvegarder un logiciel

Préparez la réinstallation d’un logiciel et la restauration de ses paramètres sur un nouveau PC.

Sauvegarde par logiciel

Inventaire des applications classiques Windows. Les applications du Microsoft Store et certains logiciels portables peuvent être absents.

Fermez le logiciel avant la copie. Vérifiez la méthode d’installation affichée et ajoutez son installeur si nécessaire. La récupération des paramètres dépend des éléments détectés ; licences et connexions peuvent rester à réactiver.

Messagerie

Sauvegardez les données locales Outlook et Thunderbird.

E-mails locaux

Les profils Thunderbird, les fichiers de données Outlook (.pst, y compris dans Documents\Fichiers Outlook) et vos signatures Outlook seront copiés. Fermez ces applications avant de lancer l’opération.

Les fichiers .ost ne sont pas copiés : ce sont des copies locales de boîtes en ligne, retéléchargées automatiquement. Le nouvel Outlook et les webmails conservent vos messages en ligne.

Wi-Fi et pilotes

Exportez les profils réseau et les pilotes installés.

Outils système

Les mots de passe Wi-Fi sont chiffrés dans la sauvegarde avec votre mot de passe de protection (Paramètres). Ils ne sont jamais écrits en clair sur le disque de sauvegarde.

Restauration

Remettez vos fichiers, profils, programmes et réglages sur ce PC depuis une sauvegarde.

Source de restauration

Aucun dossier choisi. Choisissez le disque ou dossier de sauvegarde, ou directement une version.

Restauration complète

Les fichiers déjà identiques sont ignorés ; un fichier différent déjà présent est conservé sous le nom « … (avant restauration) ». Un profil de navigateur ou de messagerie existant est mis de côté en entier. Fermez les navigateurs et la messagerie avant de commencer.

Licences de cette sauvegarde

Logiciels sauvegardés

Choisissez le dossier principal, le dossier Logiciels ou une sauvegarde individuelle. « Installer et restaurer » installe le logiciel absent, puis applique ses paramètres. Ajoutez un installeur si nécessaire. Un EXE peut ouvrir un assistant ; MSI et Winget permettent une installation automatique. Fermez le logiciel s’il est déjà installé. Des droits administrateur peuvent être requis. Les fichiers remplacés sont conservés dans la source. Activation et connexion restent à vérifier.

Navigateurs

Fermez le navigateur concerné avant la restauration. Les mots de passe Chromium sont liés à la session Windows d’origine.

Checklist avant réinstallation

Vérifiez les étapes essentielles avant de réinstaller Windows ou de changer de PC.
