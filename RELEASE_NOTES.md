# Sauvegarde PC 1.10.1

- Recherche automatique des nouvelles versions GitHub au lancement, puis toutes les six heures.
- Proposition de mise à jour intégrée au thème Aurora, avec installation après confirmation.
- Téléchargement HTTPS et contrôle SHA-256 de l'installeur avant exécution.
- Mise à jour bloquée pendant une sauvegarde ou une restauration.
- Recherche manuelle et option de recherche automatique dans Paramètres.
- Menu latéral stable, confirmations intégrées et installation/restauration par logiciel.

Cette version doit être installée une première fois sur les PC utilisant une
version antérieure à 1.10.1. Les versions suivantes pourront ensuite être proposées
depuis l'application. Windows x64 et Microsoft WebView2 sont requis.

Les sauvegardes et les réglages utilisateur restent à leur emplacement habituel.
